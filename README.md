# OMAD Tracker

เว็บแอปติดตามการกินแบบมื้อเดียว (One Meal a Day) สำหรับใช้ส่วนตัว ออกแบบให้ใช้บนมือถือก่อน และติดตั้งเป็นแอปจาก Chrome ได้

ข้อมูลอยู่บนเครื่องของคุณเท่านั้น ไม่มีบัญชีผู้ใช้ และไม่ใช่คำแนะนำทางการแพทย์

## ใช้ยังไง

- เปิดติดตามวันนี้ แล้วตัวจับเวลาอดอาหารจะเดินจากเวลาจริง ปิดแอปแล้วเปิดใหม่เวลายังถูก
- กดเริ่มกินเมื่อถึงมื้อ แล้วกดจบมื้อเมื่อกินเสร็จ
- วันที่ไม่ได้เปิดติดตามจะไม่ถูกนับว่าทำไม่สำเร็จ
- ส่งออก JSON เพื่อสำรอง แล้วนำเข้าได้ภายหลัง ปุ่มวงกลมรูปไฟล์อยู่บนหัวแอปและในหน้าตั้งค่า
- ปุ่มวงกลมตารางส่งออกไฟล์ Excel (.xlsx) มีแดชบอร์ด รายวัน และรายเดือน พร้อมสีและกรอบ เปิดใน Excel ได้เลย
- เว็บที่เปิดจาก GitHub คือ https://yusran017.github.io/Omad/ ข้อมูลยังอยู่บนเครื่องที่เปิด ไม่มีบัญชีผู้ใช้
- บน Chrome เปิดเมนูแล้วเลือกติดตั้งแอป เพื่อปักไอคอนบนหน้าจอ

## สำหรับนักพัฒนา

```bash
npm install
npm run dev
```
