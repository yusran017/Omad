## 2024-10-14 - Add icon to Cancel Eating button
**Learning:** Adding icons to text buttons makes them more visually distinct, especially when placed next to another button that already has an icon. It improves UI consistency and the scannability of actions.
**Action:** Always check adjacent buttons or similar actions in a view to ensure a consistent use of icons (either all have icons, or none do, unless one is specifically meant to be a primary action that stands out).
